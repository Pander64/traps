# traps

Harmless **test fixture** for [IoC Sentinel](https://github.com/JuanChavarriaU/ioc-sentinel) (Vultr Agent Rush, Track 01 - Blast Radius Zero).

A fictional brand ("Northwind Credit Union") page that exercises a sandboxed analysis browser:
a cross-domain credential form (posts to a `.example` domain that does not resolve), cloud-metadata and
internal-network probes, a hidden prompt-injection string aimed at the analysis LLM, and an automatic
download of random bytes. It collects nothing and impersonates no real organization.

Live page: https://pander64.github.io/traps/
